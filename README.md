# لوحة تحكم ومتابعة مشروع عشرة (Ashara Admin Dashboard)

لوحة تحكم تفاعلية ويب مستقلة لمتابعة إنجاز تيم مشروع عشرة لجمع داتا لغة الإشارة العربية، متصلة مباشرة بقاعدة بيانات **Supabase**.

## ✨ المميزات
- **لوحة متابعة حية:** إحصائيات مباشرة لعدد العينات، المساهمين النشطين، ونسبة الإنجاز الإجمالية.
- **بروفايل مخصص لكل عضو في التيم:** معرفة الحروف التي أنجزها كل مساهم وعدد عيناتها ونسبة تغطيته للـ 31 حرف.
- **شبكة الحروف الـ 31:** كروت تفاعلية ملونة توضح حالة كل حرف (مكتمل، قيد الجمع، لم يبدأ).
- **سجل الجولات المرفوعة:** جدول تفصيلي بآخر العينات المرفوعة ووقت تسجيلها.
- **تصدير التقارير:** تصدير ملخص الداتا بصيغة CSV بضغطة زر.
- **مربوطة بنفس قاعدة البيانات:** تعمل فوراً بدون أي سيرفر محلي عبر Supabase REST API.

## 🚀 كيفية التشغيل
- **محلياً:** يكفي فتح ملف index.html في أي متصفح ويب (Chrome / Edge / Firefox).
- **أونلاين:** يمكنك رفعه بضغطة زر إلى Vercel أو Netlify أو GitHub Pages.

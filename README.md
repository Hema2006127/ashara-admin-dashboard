## 🚀 المميزات الرئيسية

### 1. 🎥 استوديو جمع الإشارات أونلاين (collector.html):
- **تتبع اليد الذكي عبر المتصفح:** يعمل مباشرة عبر مكتبة **MediaPipe Hands** بدون الحاجة لتثبيت أي برامج أو بايثون على جهاز المستخدم.
- **تطابق 100% مع نموذج الـ AI:** يستخرج 126 نقطة إحداثية بدقة (63 لليد اليسرى + 63 لليد اليمنى) بصيغة [x, y, z] لكل مفصل.
- **دليل تفاعلي لكل حرف:** يعرض صورة الإشارة المعتمدة من الدليل الرسمي، مع اسم الحرف، وزاوية الكف (0°، 30°، 45°)، وتوجيه الأصابع.
- **فحص الاستقرار والمسافة:** مؤشر ذكي يحدد ما إذا كانت اليد مستقرة وجاهزة لبدء الجولة.
- **جولات قياسية (50 عينة):** عد تنازلي وتجميع سريع لـ 50 إطار لكل جولة بضغطة زر أو زر المسافة Space.
- **مؤثرات صوتية تفاعلية:** نغمات تنبيهية للعد التنازلي واكتمال الرفع مع إمكانية الكتم.
- **حفظ احتياطي بدون إنترنت (Offline Sync):** في حالة انقطاع الاتصال، تحفظ العينات محلياً مع إمكانية المزامنة السحابية فور عودة الإنترنت أو التصدير اليدوي بصيغة JSON.

### 2. 👑 لوحة التحكم والمتابعة المباشرة (index.html):
- **إحصائيات حية Realtime:** ترتبط بـ Supabase وتستقبل أي عينة جديدة ترفع فوراً عبر WebSockets.
- **بروفايل مخصص لكل عضو في الفريق:** تفاصيل عينات كل مساهم، الحروف التي أنجزها، ونسبة تغطيته للـ 31 حرفاً مع فلترة سريعة.
- **مخططات بيانية تفاعلية (Chart.js):** ترتيب المساهمين، ومستوى اكتمال كل حرف نحو الهدف (100 عينة).
- **تصدير تقارير CSV:** تحميل ملف إكسل بجميع العينات وتاريخ ووقت رفعها بنقرة واحدة.
